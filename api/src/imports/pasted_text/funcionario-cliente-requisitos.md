O sistema deverá permitir a edição dos dados da Tabela 01 (exceto o login). Para alteração da senha será necessário a confirmação da senha atual.  O sistema deverá validar os campos obrigatórios antes de salvar as alterações, garantindo a consistência dos dados. Para selecionar o funcionário que sofrerá alterações deverá haver uma busca por meio do seu login. O sistema deverá solicitar confirmação antes da inativação. Caso a operação seja confirmada, o sistema deverá alterar o status do usuário para Inativo. Caso o funcionário a ser inativado seja um profissional e houver algum agendamento de serviço futuro por esse profissional, o agendamento deverá ser inativado, e o cliente relacionado deverá receber uma notificação de cancelamento. Usuários inativos não poderão acessar o sistema.
